# Aqar (عقار)

Arabic-first (RTL) real-estate marketplace: buyer and agent accounts, listings with filters (city, type, sale/rent, price, bedrooms), favorites, mortgage calculator, public inquiry form with spam protection, agent inquiry inbox with replies, admin approval queue, plans (Free live, Pro draft) and an admin dashboard with audit log. Seed listings are marked "sample".

Live: https://real-state.mahmodsalah.workers.dev

Cloudflare Worker + SQLite Durable Object + static assets, no build step. Deploy: `npx wrangler deploy`.
